# Canvas 写入预算与保存重试策略

Canvas 的单次保存请求采用 24 MiB UTF-8 总预算，内层 Nginx 采用略高的 25 MiB 限制，使业务 API 能对接近上限的请求返回可识别错误。确定性保存失败保留本地待保存快照但停止自动重试；仅网络错误、限流和服务端暂时错误使用有上限的指数退避。该选择避免无限重试放大确定性错误，同时不把请求体上限设为无限。

## Consequences

单个快照与单个 SVG 预览各保留 10 MiB 上限，但组合请求仍受总预算约束。局域网直接 Compose 部署只需配置 Web 容器内的 Nginx；将来新增外层反向代理时必须保持至少相同的请求体限制。
